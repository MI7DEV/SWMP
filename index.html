CAPACIDADES DO SISTEMA

O que o SWMP oferece

Engenharia reversa ao serviço da Aliança — multijogador onde nunca existiu.

⚔
Divisão de Unidades
Host controla metade do esquadrão, cliente a outra metade. Sincronização automática de turnos em tempo real.
🔄
Relay WebSocket
Servidor Python local com relay persistente. Latência mínima para jogar em rede local (LAN) ou internet.
🎮
Gestor de Mods
Integração com Nexus Mods — navega os 30 mais endorsados, instala e sincroniza entre os dois jogadores automaticamente.
🔍
Explorer de Classes
Captura as classes internas do UE5 via UE4SS para mapeamento preciso das unidades e sincronização de ações.
⚡
Auto-Setup
Um clique no start.bat instala tudo — Python, WebSockets, UE4SS, mod Lua — e abre o painel de controlo.
🛡
Watchdog Automático
O servidor reinicia automaticamente se cair. API key do Nexus guardada localmente em config.json.
PROTOCOLO DE ACTIVAÇÃO

Como Funciona

Três passos para comandar o esquadrão com o teu aliado.

01
Host Inicia
Executa start.bat. O servidor arranca e o painel do host abre no browser.
02
Amigo Conecta
Acede ao link do host ou usa a página "Juntar ao Jogo" com o IP fornecido.
03
Explorar & Jogar
Com o jogo aberto numa missão, clica "Explorar Jogo" para sincronizar e dividir as unidades.
04
Mods Opcionais
Navega os top 30 mods do Nexus, instala os que quiser — ambos ficam sincronizados automaticamente.
